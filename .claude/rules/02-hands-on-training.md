# 手写训练开发纪律（沿用 llm_wiki_selfbuild 经验 📌）

> 2026-07-22 确立。核心原则：关键逻辑手写理解，样板代码 AI 提速。

## 必须优先手写（学习阶段）

**判定标准**：代码承载核心思维模型，写错 = 概念理解不到位。

### LangGraph Agent 学习路线

1. **Graph 核心骨架**：State 定义、节点函数、`add_node`/`add_edge`/`add_conditional_edges` 编排、循环终止条件
2. **核心机制 Demo**：Checkpointer 持久化、Human-in-the-loop 中断/resume、多智能体消息传递
3. **基础工具调用、ReAct 循环逻辑**
4. **数据流规则**：状态覆盖、消息追加、历史管理

> 口诀：这块代码是 Agent 状态流转的核心，口头描述讲不清楚 → 一定手写。

## 放心交给 AI（Vibe Coding）

模型初始化 / LangSmith 配置 / 异常重试装饰器 / SSE 接口适配 / 文件读写 / Prompt 模板 / 依赖与 Dockerfile / 外围工具。

## 混合模式

中等复杂度：AI 生成外围骨架 → **删除 Graph/State/节点流转代码 → 独立手写核心** → 外围复用。

## 落地判断

```
准备写代码
  ├── LangGraph 核心调度逻辑？ → 看懂思路，清空代码，独立手写
  ├── 样板胶水/集成/配置？ → AI 生成，逐行审查
  └── 灰色复杂项目 → AI 骨架 + 核心手写
```

## 执行纪律

1. 新知识点的第一个 Demo 强制手写（条件分支/人在回路/多智能体）
2. 同一模式手写复现 1~2 次后，同类场景放开 AI 提速
