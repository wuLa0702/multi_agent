> 2026-08-06 依《方案-文档重分类与目录治理-v1》同步：新增 `docs/archive/`（归档目录）、
> 删除 `docs/评审/`（空目录）、文件名规范以治理方案 §6.0「类型 × 目录」全表为准。

## 目录归属表

| 目录 | 放什么 | 示例 |
|------|--------|------|
| `docs/方案/` | 已定方案（文件名带「方案-」） | 方案-后端基础架构 |
| `docs/decisions/` | **评审稿（设计-/计划-/测试计划-）/ 决策记录（决策-，不转正）** | 设计-人在回路与Rubric评分、决策-deepagents-Profiles |
| `docs/架构/` | 架构蓝图与接口真相源 | 多agent项目-架构目录、参考-后端接口 |
| `docs/learnings/` | 踩坑与经验沉淀（日期前缀） | 2026-08-04-PyCharm索引未解析引用 |
| `docs/学习/` | 学习笔记 / 调研梳理（学习- 前缀） | 学习-harness |
| `docs/archive/` | **已废弃/被覆盖文档（git mv 保历史，不删）** | 后端开发计划、设计-记忆抽取子代理 |

## 规则

1. **新建文档先判断性质**：方案？评审稿？决策？学习？踩坑？→ 再落位，不随手放；文件名类型前缀见治理方案 §6.0 全表
2. 拿不准归属 → 问 co-creator，不猜
3. **移动文档用 `git mv`**（保留 git 历史），并同步更新引用它的文档
4. 文档内部格式规则仍以 `docs/文档规范.md` 为唯一载体（本规则只定目录归属）
5. **评审通过 → 按治理方案 §6.3 转正**（改名「方案-」+ 移入 `docs/方案/` + 更新 `docs/索引.md`）；**新增/改名/归档同步更新索引**
