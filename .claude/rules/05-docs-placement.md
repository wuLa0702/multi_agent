## 规则

1. **新建文档先判断性质**：架构真相源？规则？方案？评审稿？学习？踩坑？→ 再落位；**类型×目录全表 + 命名规则**（动态文档 `主题.md` 无前缀 / 过程文档 `YYYY-MM-DD-类型-主题-vN.md`）见 `docs/规则/文档治理规则.md`
2. 拿不准归属 → 问 co-creator，不猜
3. **移动文档用 `git mv`**（保留 git 历史），并同步更新引用它的文档
4. **双向链接**：A 引用 B ⇒ B 反向引用 A；每个文档关联段回链 `docs/索引.md`；权威 ↔ 镜像互标（详见 `docs/规则/文档治理规则.md` §4）
5. **评审通过 → 转正**：`git mv docs/决策/设计-X-v1.md docs/方案/方案-X-v1.md` + 版本记录追加 + 更新 `docs/索引.md`；**新增/改名/归档同步更新索引**
6. 文档格式规则以 `docs/规则/文档规范.md` 为唯一载体（本规则只定目录归属）
