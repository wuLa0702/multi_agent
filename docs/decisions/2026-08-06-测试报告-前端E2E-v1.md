## 3. 发现并修复的问题（3 个，均 mock 适配）

| # | 问题 | 根因 | 修复 | 提交 |
|---|------|------|------|------|
| 1 | 审批批准后消息区被清空 | mock 模式 done 后 refreshMessages 拉**真实后端**（5176 环境可达）空结果 → `set(messages: [])` 覆盖本地 mock 流消息 | mock 模式跳过 refreshMessages（`!MOCK_ENABLED` 才重拉） | `e9bba09` |
| 2 | 上下文用量恒显示 0 | ContextUsage 查 `GET /v1/context-usage`，真实后端返回 0（mock 流未落库）覆盖 store 的 done 事件值 | 组件优先 store（SSE done 携带），API 仅 store 空时兜底 | `5e07e7c` + 13:04 store 优先 |
| 3 | 多次 HMR 后页面跑陈旧代码 | vite HMR 模块缓存（Fast Refresh 保留组件 state/订阅旧 store 实例） | 重启 dev server 干净加载；非代码 bug，测试方法学记录 | 无代码改动 |

> 注：问题 1/2 为 mock 数据源与真实后端并存环境的适配缺口，**真实后端联调模式下不影响**（refreshMessages/查表均为正常路径）。
