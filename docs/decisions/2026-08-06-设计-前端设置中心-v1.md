## 1. 总：背景、目标与范围

### 1.1 背景

后端配置持续多样化（记忆子代理开关、抽取专用模型、沙箱池参数、事件流、
解释器等）——目前只能改 `.env` + 重启，前端不可见、用户不可配。
需前端设置中心：**界面上可视化配置后端设置**。

### 1.2 目标

1. 设置中心 + **二级菜单**：按配置域分组（Agent/沙箱/技能/安全…）
2. **DB 持久化**：基础化配置信息入库（非仅 .env），支持**重置为默认配置**
3. **回显**：已配置数据前端可见
4. **密钥组件**：带复制功能的密码显隐输入框（API key 等）
5. **重置当前页面** + **保存必须确认**

### 1.3 范围

| 在本方案内 | 不在本方案内 |
|-----------|-------------|
| 设置中心前端页面 + 二级菜单 | 权限体系（多用户/角色）——单机单用户 |
| app_config 表 + 配置 API（GET/PUT/RESET） | 配置变更热生效（需评估：部分配置需重启，标注） |
| 密钥显隐复制组件 | 配置版本历史/审计面板（可后续） |
| 保存确认 + 重置当前页 | 云上多实例配置同步 |

## 3. 分·设计

### 3.1 配置分类与二级菜单

```
设置中心（一级）
├── Agent 设置          ← 记忆子代理开关/抽取模型/事件流开关/解释器开关
├── 沙箱设置            ← URL/池上限/CPU/内存/快照 ID
├── 技能设置            ← 技能目录（只读展示）/PTC 白名单
├── 对话设置            ← 代理模式默认/记忆注入条数
└── 安全设置            ← API Key 类（密钥组件）/CORS
```

- 每个二级菜单 = 一个配置分组表单（分组加载/保存，不是整页全量）
- 配置项元信息：`{key, label, type(switch/number/text/secret/select), default, group, description}`

### 3.2 DB 持久化与优先级

```
配置优先级（运行时生效）：DB 覆盖（app_config）> .env（Settings）> 代码默认值
```

- `app_config` 表存"用户已覆盖的配置"（key/value/type/group/is_secret）
- Settings 加载后，DB 覆盖层二次覆盖（`settings_override` 机制）——
  ⚠️ 敏感项（密钥）默认不落 DB 明文（存加密或仅存引用，见 §3.4）
- **未在 DB 的配置项**：回显 .env/默认值（前端可见但"未自定义"标记）

### 3.3 重置

| 重置粒度 | 行为 |
|---------|------|
| **重置当前页面**（用户需求） | 未保存的表单恢复为加载时值（前端级，丢弃未保存修改） |
| **重置为默认配置**（DB 级） | 删除该组 DB 覆盖 → 回落到 .env/默认值；密钥类重置 = 清除 DB 值 |

- 两种重置都需**确认弹窗**（重置当前页面 = 丢弃未保存修改确认；重置默认 = 覆盖确认）

### 3.4 密钥输入框（显隐 + 复制）

```
[API Key   ] ************  [👁 显示/隐藏] [📋 复制]  [已配置/未配置]
```

| 行为 | 约定 |
|------|------|
| 显隐 | `type=password` ⇄ `type=text` 切换（点击眼睛图标） |
| 复制 | 显示状态下点击复制（复制明文；隐藏状态复制不可用或提示先显示） |
| 回显安全 | **不回显明文**——已配置时显示掩码占位 + "已配置"标记；修改需重新输入 |
| 保存 | 输入框留空 = 保持原值；有值 = 覆盖（落 DB 前加密/仅存引用，见风险项） |

### 3.5 保存确认

- **保存按钮二次确认**：修改后点保存 → 确认弹窗（列出本次变更项）→ 确认才提交
- 页面离开未保存修改 → 提示（beforeunload / 路由守卫）
- 保存成功 → 轻提示 + 标注"部分配置需重启生效"

## 4. 分·API 设计

```
GET  /v1/settings                # 全部分组配置（含 default/当前值/是否自定义）
GET  /v1/settings/{group}        # 单分组（回显用）
PUT  /v1/settings/{group}        # 保存分组（敏感字段：留空=保持原值）
POST /v1/settings/{group}/reset  # 重置该组为默认（清 DB 覆盖）
```

响应模型（Pydantic，禁裸 dict——10-api.md）：

```python
class SettingItem(BaseModel):
    key: str
    label: str
    type: Literal["switch", "number", "text", "secret", "select"]
    value: str | int | bool | None      # secret：None 或掩码占位（不回显明文）
    default: str | int | bool | None
    customized: bool                     # 是否 DB 覆盖（回显"已配置/默认"标记）
    description: str = ""

class SettingGroup(BaseModel):
    group: str
    items: list[SettingItem]
```

- 敏感字段（is_secret）：GET 返回掩码/None + customized 标记；PUT 留空 = 保持原值
- 部分配置（如 sandbox_url）变更后需重启——响应标注 `restart_required: bool`

## 5. 分·数据库设计（app_config 表）

```sql
CREATE TABLE IF NOT EXISTS app_config (
    key          TEXT PRIMARY KEY,          -- 配置键（对应 settings 字段名）
    value        TEXT,                      -- 配置值（JSON 序列化；secret 存加密/引用）
    group_name   TEXT NOT NULL,             -- 配置分组（agent/sandbox/skill/chat/security）
    value_type   TEXT NOT NULL DEFAULT 'text',  -- switch/number/text/secret/select
    is_secret    INTEGER NOT NULL DEFAULT 0,    -- 敏感标记（回显脱敏）
    label        TEXT,                      -- 前端展示名
    description  TEXT DEFAULT '',           -- 说明
    updated_at   TEXT NOT NULL              -- UTC ISO（更新时间）
);
```

- `updated_at` 供审计/回显"最后修改时间"
- 与 `core/config.py` Settings 的映射表：字段名 ↔ 分组/类型/默认值（§7 代码）

## 6. 总·优先级与风险自检

### 6.1 优先级

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| **P0** | app_config 表 + Settings 覆盖机制 + 配置 API（GET/PUT/RESET + 脱敏） | 中 |
| **P1** | 前端设置中心页面 + 二级菜单 + 分组表单（回显/保存确认/重置当前页） | 中 |
| **P2** | 密钥显隐复制组件 + 重置为默认 + 热生效评估 | 中 |
| **P2** | 配置审计/版本（可选） | 小 |

### 6.2 风险自检清单

- [ ] **密钥落库安全（最高）**：secret 值落 DB 需加密（或存引用不存值）——
      .env 是 gitignore 的密钥唯一源，DB 落明文违背 00-security 精神；
      方案：DB 只存加密值或"是否已配置"标记（值仍留 .env）——评审决策点
- [ ] **热生效边界**：多数配置加载于进程启动（Settings 单例）——DB 覆盖需
      运行时刷新机制或标注"重启生效"；重启生效的配置在前端明确提示
- [ ] **优先级正确性**：DB 覆盖 > .env——若 DB 误配，覆盖了 .env 正确值；
      "重置默认"是恢复手段 ✓
- [ ] **回显不泄密**：secret 组件掩码 + 不回显明文——前端代码不缓存明文
- [ ] **保存确认防误**：二次确认 + 变更项清单展示
- [ ] **先红后绿**：API 测试先行；提交前 pytest 全绿
