## 现象

代码改动/新增文件后，PyCharm 编辑器里出现大量"未解析的引用"红色波浪线
（如 import 报错、符号找不到），但命令行运行 pytest / uvicorn 完全正常。

**判断口诀**：命令行能跑 = 代码没坏，是 IDE 索引问题，**不要当 bug 排查**。

## 根因

PyCharm 的项目索引（符号解析缓存）没有及时刷新：
- 新增文件/目录后索引未重建
- Python 解释器指向变化（如 .venv 重建）后未重新关联
- `.idea/` 缓存损坏或过期

## 处理

按顺序尝试（第一个通常就够）：

1. **File → Invalidate Caches… → Invalidate and Restart**（清缓存重启，最常用）
2. **确认解释器**：Settings → Project → Python Interpreter → 选项目 `.venv`（`D:\gtiHub\multi_agent\.venv`）
3. **标记源根**：新增的顶层目录（如 `backend/`、`frontend/src/`）右键 → Mark Directory as → Sources Root
4. 仍不行：关闭 PyCharm → 删除项目根 `.idea/` 目录 → 重新打开项目（会全量重建索引）

## 预防

- 大改动（新增多文件/目录）后，让 PyCharm 自动索引完成（右下角进度）再检查红波浪线
- 改动后可用 `Ctrl+Shift+F10`（运行当前文件）验证——能跑就说明代码没问题
- 项目命令验证优先于 IDE 提示：`pytest` / `tsc -b --noEmit` 全绿 = 代码正确
