# bat 三坑：文件编码 / WSL bash 误命中 / 块内括号

> 2026-08-03 追加「WSL bash 误命中」与「if 块内括号」两坑（同域合并，不另开篇）。

## 坑二：`where bash` 在 cmd 默认 PATH 命中 WSL 启动器（co-creator 实测报错）

### 现象

cmd 里跑 `dev-restart.bat` 报：
`<3>WSL (88125 - Relay) ERROR: CreateProcessCommon:735: execvpe(/bin/bash) failed: No such file or directory`

### 根因

- Windows 默认 cmd PATH 里 `C:\Windows\System32` 在最前，而 System32 自带 `bash.exe`（**WSL 启动器**）
- bat 里 `where bash` 取第一个命中 → 拿到 WSL 启动器，不是 Git Bash
- 本机 WSL 无发行版 → WSL Relay 找不到 `/bin/bash` → 上面的错
- 复现方法：`set PATH=C:\Windows\System32;%PATH%` 后再跑即必现（我环境 Git 在前所以初测没暴露——**验证环境 PATH 顺序 ≠ 用户环境，脚本不能假设 PATH**）

### 修复

bat 不依赖 PATH，用 Git for Windows 固定路径：
```bat
set "GIT_BASH=%ProgramFiles%\Git\bin\bash.exe"
if not exist "%GIT_BASH%" set "GIT_BASH=%ProgramFiles(x86)%\Git\bin\bash.exe"
if not exist "%GIT_BASH%" (
    echo [ERROR] ...
    exit /b 1
)
"%GIT_BASH%" scripts/dev.sh
```
绝不 fallback 到裸 `bash`/`where bash`（WSL 坑）。

## 坑三：if 括号块内 `echo (xxx: yyy)` 破坏块解析

### 现象

错误分支写 `echo (WSL bash is NOT supported: dev scripts need the MSYS environment)`，实测：整个 if 块静默失效（echo 全无输出），退出码异常（变体 A/B 二分确认：删该行即恢复）。

### 根因

cmd 的 `if (...)` 块解析对块内**行首 token 以 `(` 开头**（+ 冒号）有老 bug：嵌套括号计数/标签解析错乱 → 块结构崩。这是 cmd 解析器历史缺陷区，不深究精确机制，**实证结论**：块内 echo 不要用括号开头、不要含 `(` `)`。

### 修复

错误分支提示改成 `[HINT] ...` 前缀，去括号。

## 坑一：UTF-8 无 BOM 中文注释在 cmd 下解析乱码

### 现象

## 现象

`scripts/dev.bat` 首版用 UTF-8 无 BOM 保存，注释含中文。cmd 直跑时报一串怪错：
`'sh（需' 不是内部或外部命令`、`'脚本中文' 不是命令`、`'RROR]' 不是命令`。
看起来 rem 注释行被拆开当成命令执行了。

## 根因（不是表面坑）

- **cmd 解析 .bat 文件时用系统 ANSI 代码页（中文系统 = GBK/936），而不是控制台当前代码页**
- `chcp 65001` 只影响输出显示编码，**不影响 bat 文件本身的解析**
- UTF-8 中文多字节序列在 GBK 下可能包含 `0x0A`（换行）等控制字节 → 注释行提前截断、错位 → 残片被当命令
- 与 .sh 不同：bash 默认按 UTF-8 解析脚本文件，中文注释安全；cmd 无此保障

## 修复

**bat 文件内只用 ASCII**（英文注释/提示），中文说明放被转交的 .sh 里：
- `.sh` 文件（bash 解析，UTF-8 安全）：中文随便写
- `.bat` 文件（cmd 解析，ANSI 只认）：全 ASCII
- 输出编码需求由 `chcp 65001` 交给运行时，脚本输出（UTF-8）在 cmd 里正常显示

## 验证

`cmd /c scripts\dev.bat` 全链路跑通：docker 资源 + vite 5176 + 后端 8010 就绪。

## 通用化

Windows 下任何要进 cmd 的批处理文件（.bat/.cmd）一律：
1. 全 ASCII 内容
2. 需要中文输出 → chcp 65001 + 英文注释
3. 复杂逻辑交给 .sh，bat 只做定位 + 转交（薄包装）
