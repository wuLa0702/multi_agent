## 1. F1 模型单价编辑（P0） 🔴 v1

### 交互
- 位置：**SettingsPage 新增「模型管理」区**（或 ModelSelector 旁齿轮入口）
- 模型列表（来自 `GET /v1/providers`）→ 每行显示：模型名 + `input_price`/`output_price` 两个数字输入框（元/千 token，步长 0.001，默认显示当前值）
- 每行「保存」按钮 → `api.updateModelPrice(id, input, output)` → 成功 Toast「已生效」；404 → 提示「模型不存在」

### 组件
```tsx
// components/settings/ModelPriceList.tsx
props: { providers: ProvidersResponse }
state: { prices: Record<modelId, {input: string; output: string}>, saving: boolean }
```
- 行内编辑（不入库，点保存才提交）；空值/负数前端校验拦截

### API 对接（client.ts 新增）
```ts
updateModelPrice(id: number, inputPrice: number, outputPrice: number) {
  return request<{ status: string; model_id: number }>(
    `/v1/providers/models/${id}/price`,
    { method: "PATCH", body: JSON.stringify({ input_price: inputPrice, output_price: outputPrice }) },
  );
}
```

### 边界
- 单价为 0 允许（内置模型有预填官方价，自定义默认 0 由用户填）
- 保存失败：保留输入值 + 错误提示，不刷新丢输入

## 2. F2 成本展示（P0） 🔴 v1

### 交互
- 位置：**ChatPage 对话框下方或侧栏「成本」区块**（会话级）；SettingsPage 可选加全局汇总
- 展示：`total_cost`（¥ 4 位小数）+ `input/output_tokens` + `alert_count` 徽标
- 切换会话时刷新（`GET /v1/cost/summary?session_id=`）

### 组件
```tsx
// components/chat/CostPanel.tsx
props: { sessionId: string }
state: { summary: CostSummary | null, alerts: CostAlert[] | null, loading: boolean }
```
- `useEffect(sessionId)` → `api.getCostSummary` + `api.getCostAlerts`（并行）
- 告警列表可展开（threshold/total_cost/created_at）

### API 对接
```ts
getCostSummary(sessionId: string) {
  return request<{ session_id: string; total_cost: number; input_tokens: number; output_tokens: number; alert_count: number }>(
    `/v1/cost/summary?session_id=${sessionId}`);
}
getCostAlerts(sessionId: string) {
  return request<{ status: string; items: CostAlertItem[]; total: number }>(`/v1/cost/alerts?session_id=${sessionId}`);
}
```

### 边界
- 404 `COST_NOT_FOUND`（无流水）→ 显示「暂无成本记录」，不报错
- 新会话首次：空态

## 3. F3 cost_alert SSE 事件处理（P1） 🔴 v1

### 后端事件契约（实证 `schemas/events.py:99`）
```ts
// types.ts SSEEvent 联合类型加分支
{ type: "cost_alert"; session_id: string; total_cost: number; threshold: number }
```
- 事件在流中 **done 前** 发一次（run 内去重）

### 处理（chatStore.ts 加 case）
```ts
case "cost_alert": {
  // Toast/notice：`成本已超 ¥${event.threshold}`（分级告警 5/10/20）
  toast(`成本告警：已超 ¥${event.threshold}（当前 ¥${event.total_cost}）`, "warning");
  set({ lastCostAlert: event });  // CostPanel 可引用刷新
  break;
}
```

### mock.ts 补样例
```ts
{ type: "cost_alert", session_id, total_cost: 12.5, threshold: 10 }
```

### 边界
- 后端 run 内已去重（同阈值一次）；前端侧 toast 幂等（同阈值不重复弹）
- done 后流结束，不重复触发

## 4. F4 MCP 管理 UI（P1） 🔴 v1

### 交互
- 位置：**SkillsPage 加「MCP 连接」Tab**（或独立区域）
- 列表：来源 URL + 启用状态（Switch）+ 启停/删除按钮
- 启停 → `api.updateMcpServer(id, is_active)`；删除 → 确认弹窗 → `api.deleteMcpServer(id)`

### 组件
```tsx
// components/skills/McpServerPanel.tsx
state: { servers: McpServer[], loading: boolean }
```
- 复用 `InstalledSkillRow` 行布局模式

### API 对接
```ts
listMcpServers(): request<{ items: McpServer[] }>("/v1/mcp-servers");
updateMcpServer(id: number, isActive: boolean): request<{ status; id; is_active }>(`/v1/mcp-servers/${id}`, { method: "PATCH", ... });
deleteMcpServer(id: number): request<{ status; id }>(`/v1/mcp-servers/${id}`, { method: "DELETE" });
```

### 边界
- 404 `MCP_SERVER_NOT_FOUND` → 提示 + 刷新列表
- 启停触发后端工具热刷新（失败不阻断，前端只提示「已提交」）

## 5. F5 设置中心对齐（P2） 🔴 v1

### 交互
- SettingsPage 已有基础 → 补：**业务开关从 DB 读**（`GET /v1/settings` → 渲染各开关）→ 改动即 `PUT /v1/settings`
- 后端热更新未做（P2）→ 保存后提示「已保存，后端生效需重启」（诚实提示，防误导）

### API 对接
```ts
getSettings(): request<{ settings: Record<string, string> }>("/v1/settings");
putSettings(values: Record<string, string>): request<{ status; updated: string[] }>("/v1/settings", { method: "PUT", ... });
postFrontendLogs(entries): request<{ status }>("/v1/frontend/logs", { method: "POST", ... });
```

### 边界
- 空表 → 前端用默认值兜底渲染
- 开关改动节流保存（防抖 500ms），失败回滚 UI

## 6. F6 文件引用渲染（P2） 🔴 v1

### 交互
- 消息正文含 FileRef（name/path/content_type/size）→ 渲染为**文件卡片**（图标 + 文件名 + 大小）
- 路径**直接展示后端返回的相对路径**，前端不做拼接/校验（后端 FileRef validator 已拦截越权）

### 组件
```tsx
// components/chat/FileRefChip.tsx
props: { ref: FileRef }
```
- 复用 `agent-elements/icons/file-ext-icon.tsx` 按扩展名选图标

### 边界
- 后端已校验 path（非法抛错/降级），前端信任契约
- 空 ref / 超长名：截断展示 + tooltip 全文
