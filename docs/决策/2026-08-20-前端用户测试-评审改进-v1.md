### 0.2 token 含义查证（Q2 依据）

| 字段 | 含义 | 来源 |
|------|------|------|
| **输入 token** | 本轮累计输入 token（上下文 + 用户消息）| `token_usage.py` `_log_cost_for_round` 读 session context_used |
| **输出 token** | 本轮累计输出 token（LLM 生成）| `token_cost_ledger.output_tokens` 累计 |
| **总 token** | 输入 + 输出 | 页面显示 |
| **最大 token** | 上下文窗口上限（默认 128k，可调）| `context_total`（SettingsPage 滑杆配置）|
| **成本** | 单价 × 增量 token（元/千 token）| `token_cost_ledger` 每轮落流水 |
| **"602-0"** | 602 输入 / 0 输出（首轮，输出还没计/差量=0）| `_log_cost_for_round` 顺序 bug 已修（先算增量再更新 context_used）|

**页面展示**：输入/输出 token + 最大 + 成本 + **问号图标 hover 说明计算公式**

## 3. 通用规范：图标 + hover tooltip 🔴 v2

> co-creator 定案：全项目采用**图标 + hover tooltip**规范，用于解释功能含义。

**规范**：
- 需要解释的字段/功能旁加小型 `?` 图标（`lucide-react` 的 `HelpCircle`）
- hover 弹出 tooltip（说明文字，简洁 ≤50 字）
- 适用场景：token 含义、成本计算、模式说明、工具功能、上下文指标等

**统一组件**（新建 `components/shared/HelpTooltip.tsx`）：
```tsx
// 用法：<HelpTooltip content="输入 token = 本轮累计 LLM 接收的 token 数" />
```
- 基于 shadcn/ui 的 Tooltip 组件
- T2/T3/T5/T8 统一使用此组件
