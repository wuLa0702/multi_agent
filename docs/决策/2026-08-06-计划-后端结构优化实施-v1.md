## 3. 风险与防崩溃措施

| 风险 | 防崩溃措施 |
|------|-----------|
| 大量 import 修改遗漏 → 运行崩溃 | T1 先出全量引用清单；每步 grep 0 残留检查点 + import smoke |
| 文件名魔法值漏改 → 运行时找不到文件 | T4 前置盘点清单逐条核对；paths.py 已有函数优先复用 |
| 迁移破坏现有行为 | 每步跑 pytest 相关用例（不补新测试，但迁移后现有测试必须全绿） |
| 中文路径/编码问题（Windows） | 全程 worktree 绝对路径 + `git -C` 显式仓库；git mv 保历史 |
| 一次改太多失控 | 严格按步骤表：一步全绿才进下一步；每个 commit 独立可回滚 |
