## 2. 布局重构方案（5列→4列） 🔴 v1

### 2.1 现状（5 列，诊断确认）

```
一级导航(64) | 会话列表(280) | 主对话区 | 运行信息InfoPanel(280) | Agent详情AgentPanel(可开关)
```

### 2.2 目标（4 列）

```
一级导航(64) | 会话列表(280) | 主对话区(含概览标尺) | Agent详情面板(可开关, 合并运行信息+Agent)
```

**动作**：
1. **取消常驻 InfoPanel**——其内容（任务进度/成本告警/关联 Wiki）移入 Agent 详情面板顶部卡片区
2. **AgentPanel 改造为 `AgentDetailPanel`**：标题栏+关闭 + 卡片区（运行信息/成本告警/关联 Wiki/工具调用/Agent 调用链）
3. **面板可开关**：默认关（3 列，主对话区宽松）；点击 Agent 按钮展开（360px，可拖宽）
4. **主对话区**右侧保留 OverviewRuler（24px 概览标尺，已存在）

### 2.3 迁移映射

| 原组件 | 去向 |
|--------|------|
| `InfoPanel`（任务/成本/Wiki 区块）| → 并入 `AgentDetailPanel` 顶部 3 卡片 |
| `AgentPanel`（工具/子代理链）| → `AgentDetailPanel` 底部 2 卡片 |
| `ChatPage` 布局 | 移除 InfoPanel 常驻，Agent 按钮控制面板开关 |

### 3.1 成本跳转实现（修 #5）
```tsx
// CostPanel：用事件驱动跳转（App 监听 navigate → 切到 settings）
window.dispatchEvent(new CustomEvent("app-navigate", { detail: { view: "settings", section: "model-pricing" } }));
// App.tsx 监听
useEffect(() => {
  const h = (e: Event) => { const d = (e as CustomEvent).detail; setActiveView(d.view); };
  window.addEventListener("app-navigate", h);
  return () => window.removeEventListener("app-navigate", h);
}, []);
```
