## 1. mock 测试策略（自 mock 假数据）

| 层 | 方案 |
|----|------|
| mock 数据源 | 新增 `lib/api/mock.ts`：mock SSE 事件生成器（approve 事件 / subagent 流 / todos / token 流），按真实契约字段生成 |
| 接入方式 | 开发/测试环境（`import.meta.env.DEV` 或显式开关）走 mock 流代替真实 SSE；不做假后端，只做假数据源 |
| 验证 | 每批 `tsc --noEmit` 类型检查 + `vite build` 构建通过 + mock 流程浏览器实测（playwright 工具） |
| 退出 | mock 层与真实 SSE 同接口（`startChatStream`），切换一个开关即可接真后端 |

## 2. 开发批次（每批：开发 → tsc/build 验证 → mock 实测 → 独立 commit）

| 批次 | 动作 | 新增/修改 | 检查点 |
|------|------|-----------|--------|
| B1 | 一键到底 | 新增 `components/chat/ScrollToBottom.tsx`；改 `ChatMessages.tsx`（脱离 500px 检测 + 暂停自动跟随 + 未读计数） | 向上滚 500px 按钮出现；点击回底；流式时脱离不抢滚动 |
| B2 | 审批 UI | 新增 `components/chat/ApprovalCard.tsx`；chatStore 增 approve 状态机（idle/pending/submitted/resumed）；mock 触发 approve 事件 | 高危三决策/中危两决策；编辑后批准；202→resumed 恢复；RUN_NOT_FOUND 失效态 |
| B3 | 子代理模式 | 新增 `components/chat/SubagentCard.tsx`/`SubagentProgress.tsx`；chatStore 增 subagents 字段；mock subagent 事件流 | 卡片状态流转（等待/运行/完成/错误）；进度条实时；可折叠 |
| B4 | 任务规划模式 | 新增 `components/todo/TodoPanel.tsx`/`TodoItem.tsx`；chatStore 增 todos；mock todos 流 | 顶部面板；状态样式（待/进行/完成）；折叠；空状态隐藏 |

## 3. 风险与防崩溃

| 风险 | 措施 |
|------|------|
| 一次开发过多崩溃 | 严格分批：每批独立验证 + 独立 commit，全绿才进下一批 |
| 破坏现有对话流 | B1/B2 只新增组件 + 最小侵入 ChatMessages/chatStore；每批跑现有 tsc/build |
| mock 与真实契约漂移 | mock 按 `lib/api/types.ts` 字段生成，类型约束 |
| 沙箱模式过大 | 明确后置（单独计划），不混入本批次 |
