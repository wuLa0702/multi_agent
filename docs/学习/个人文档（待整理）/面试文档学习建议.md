# 面试文档学习建议

> 📌 **定位**：vibe coding 速成项目的面试备考指南——解决"22篇描述点不知道从哪入手"、"MD太干记不住"、"对代码不熟悉"三个问题。

---

## 0. 结论

**文档质量其实很高（有总分总、有 mermaid、有数据弹药、有 commit 溯源），问题不是"不够好"，是"太多+太干+没和代码挂钩"。** 22 篇平铺，vibe coding 速成没代码体感，光看 MD 肯定记不住。

三步走：
1. 建立全局观（只读 2 篇）
2. 吃透核心 6 个（面试 80% 问题集中在这）
3. 横切 + 储备按需看

四种升级方式：Obsidian 图谱 / 知识地图 / 模拟脚本 / Anki 卡片。

---

## 1. 从哪里入手：3 步学习路径

### 第 1 步：建立全局观（1 天）

**只读 2 篇**，不要贪多：

1. `面试描述点-架构总纲-v1.md` —— 分层 + 决策表 + 演进路径，先知道系统长什么样
2. `学习-项目追问链-v1.md` §7 主流程 —— 一次请求从入口到出口的完整数据流

**目标**：能对着架构总纲的 mermaid 图，自己讲一遍"用户发消息 → 系统怎么处理 → 怎么返回"，讲不下来就再看一遍。

---

### 第 2 步：吃透核心 6 个（3-5 天）

**面试 80% 的问题集中在这 6 个**，先把这几个搞透：

| 优先级 | 模块 | 为什么高频 |
|--------|------|-----------|
| ⭐⭐⭐ | 子代理 | 多 Agent 项目的核心，必问"为什么拆/怎么拆/代价是什么" |
| ⭐⭐⭐ | 对话流式 SSE | 工程实现必问，"流式怎么实现的/事件类型有哪些" |
| ⭐⭐⭐ | HITL 审批 | 亮点功能，"人在回路怎么做/中断怎么恢复" |
| ⭐⭐ | 记忆体系 | Agent 经典问题，"短期/长期记忆怎么存/怎么注入" |
| ⭐⭐ | 断点持久化 | 工程深度，"checkpoint 怎么存/resume 怎么恢复" |
| ⭐⭐ | 工具能力分层（tools vs MCP） | 概念辨析，"工具和 MCP 什么区别/为什么分层" |

---

### 第 3 步：横切 + 储备（按需）

剩下的 16 篇分两类：

- **横切三件套**（容错/成本/安全）：一起看，都是"挂在主流程上的护栏"，讲法类似
- **储备模块**（沙箱/技能/评估/Rubric/模型管理等）：面试问到了再翻，有印象就行

## 2. 不够丰富多彩：4 种升级方案

### 方案 A：用 Obsidian 看（最推荐，零成本）⭐⭐⭐⭐⭐

你本来就用 Obsidian，直接把 `docs/学习/面试/` 目录加进 Obsidian 库：

- 双向链接自动生效（文档里已经写了引用）
- 图谱视图能看到 22 篇之间的关联，一眼看清谁是核心
- 可以给每篇打标签（`#面试/核心` `#面试/横切` `#面试/储备`），按标签筛选
- 支持 mermaid 渲染，比 VSCode 里看更舒服

**操作**：Obsidian → 打开文件夹作为库 → 选 `D:\gtiHub\multi_agent\docs\` → 完事

---

### 方案 B：做一张"面试知识地图"（可视化全景）⭐⭐⭐⭐

用 mermaid 或 draw.io 画一张**全景知识图谱**，把 22 个模块按"核心/横切/储备"分层，每个模块写 1 句话 + 1 个追问点。

**结构示例**：

```
                    ┌─────────────────┐
                    │   架构总纲（入口）  │
                    └────────┬────────┘
           ┌────────────────┼────────────────┐
           ▼                ▼                ▼
      ┌─────────┐      ┌─────────┐      ┌─────────┐
      │  核心层  │      │  横切层  │      │  储备层  │
      │ 6个模块  │      │ 3个模块  │      │ 13个模块 │
      └─────────┘      └─────────┘      └─────────┘
```

**好处**：一张图代替 22 篇目录，复习时看图回忆，想不起来再点进去看详情。

---

### 方案 C：做成"面试模拟脚本"（互动式记忆）⭐⭐⭐⭐

把每篇描述点改成**自问自答的对话形式**，模拟面试官追问：

```
面试官：你这个多 Agent 系统为什么要拆子代理？
你：因为单体 Agent 有三个坑...（讲演进路径）
面试官：拆了之后有什么代价？
你：成本 +2-8 倍，延迟从 101s 到 860s...（主动讲代价）
面试官：那你怎么控制成本？
你：四件套...（自然过渡到成本控制模块）
```

**好处**：不是背知识点，是练"对话流"——面试是聊天不是考试，能顺着追问往下讲才是真会。

---

### 方案 D：Anki 间隔重复卡片（专治记不住）⭐⭐⭐

把每个模块的**核心结论 + 追问点 + 数据弹药**做成 Anki 卡片：

- 正面："成本控制四件套是什么？"
- 背面："token 统计 / 模型单价 / 缓存 / 分级告警 + 各带一个权衡点"

**好处**：vibe coding 速成的最大问题是"记不住"，Anki 用间隔重复帮你把短期记忆变长期。每天刷 15 分钟，一周就能把核心 6 个刻进脑子里。

## 3. 对代码不熟悉：文档 ↔ 代码对照法

每篇描述点都有 **commit 来源**，别光看文档，对着 commit 看代码：

```
看描述点 → 找到 commit hash → git show <hash> → 看实际改了哪些文件
         → 打开对应代码文件 → 对着文档讲一遍"这里为什么这么写"
```

### 重点跟 3 条调用链（跟完就有体感了）

1. **主链路**：`api/chat.py` → `agent/main_agent.py` → deepagents 编译图 → LLM 调用 → SSE 返回
2. **子代理委派**：主 Agent 调用子代理工具 → `subagents/loader.py` → 子 Agent 独立执行 → 结果返回
3. **HITL 中断恢复**：工具触发 interrupt → checkpoint 落库 → 前端审批 → resume 恢复执行

> 跟调用链的时候画时序图，画完你对系统的理解直接上一个台阶。
