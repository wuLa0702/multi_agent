## 项目经验

### 多 Agent 协作系统（独立开发）· GitHub 链接
**LangGraph · deepagents · FastAPI · SSE · Redis · OpenSandbox · MCP**

- 独立设计并实现多 Agent 协作平台：基于 deepagents + LangGraph 构建每会话 Agent 图（有界 LRU 缓存 + 双检锁），声明式子代理（YAML），SSE 类型化事件流（token / tool_call / subagent / approve / done）
- 实现**人在回路（HITL）审批**：LangGraph interrupt 中断 + Checkpointer 断点持久化 + Redis 待审队列，支持 approve / reject / edit / respond 四类决策，**中断后精确恢复上下文**
- 设计**跨会话记忆系统**：LLM 抽取单行事实 + 指纹去重 + 异步队列子代理，历史跨会话继承
- 打通 **MCP 双向链路**：外部 MCP 服务（SSE / HTTP / stdio）故障隔离接入 + FastMCP 服务端暴露内部工具
- 接入 OpenSandbox 沙箱（本地 Docker / 云端）执行不可信代码，资源限制 + 会话复用；实现运行时多模型切换、成本台账与告警
- 工程化：**235 个测试函数、29 个 REST 接口、9 张表 + Redis**、工具审计日志、dev/prod 双环境，**14 天迭代 331 次提交**
