## 项目经验

### LLM Wiki 知识沉淀系统

**背景**：解决"个人知识散落文档、难以沉淀复用"的痛点。基于 Karpathy「LLM Wiki」模式设计知识管理系统——由 LLM 将源文档**编译一次**为结构化、互链的 Wiki 知识库并增量更新，区别于 RAG 的查询时检索，知识越用越厚。

- 设计**双层存储**：Markdown 内容层（YAML frontmatter + 7 类页面分类）+ SQLite 元数据层（链接图 / 去重 / 任务队列 / 成本记录），内容与元数据解耦
- 实现**知识图谱 + Louvain 社区检测**，自动发现知识簇；BM25 词法检索
- 支持多格式文档解析（PDF / Word / PPTX / Excel）+ 知识质量 lint + 权限与隐私规则
- 技术：FastAPI · LangChain 多模型适配（DeepSeek / 豆包 / OpenAI）· SQLite

### 多 Agent 协作系统

**背景**：面向"Agent 长任务执行存在不确定性、需要人工把关与可靠恢复"的协作平台——主 Agent 编排子代理与工具，支持人工介入、断点续跑、跨会话记忆。

- **Agent 编排**：基于 deepagents + LangGraph 构建每会话 Agent 图，声明式子代理（YAML），SSE 流式事件（token / tool_call / approve / done）
- **人在回路（HITL）**：LangGraph interrupt 中断 + Checkpointer 断点持久化 + 待审队列，支持 approve / reject / edit / respond 四类决策，中断后精确恢复上下文
- **跨会话记忆**：LLM 抽取单行事实 + 指纹去重 + 异步子代理队列，历史跨会话继承
- **MCP 双向集成** + OpenSandbox 沙箱隔离执行不可信代码；运行时多模型切换
- 技术：FastAPI · Redis · SQLite · SSE
