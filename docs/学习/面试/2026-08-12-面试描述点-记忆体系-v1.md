## §1 总（30s）

> "记忆我做**三层**：文件记忆（AGENTS.md/tasks/decisions）+ 语义 Store（SQLite 跨会话回忆）+ `memory_agent` 并列执行体（后台队列抽取，**不阻塞对话**）。检索带时间衰减 + 窗口裁剪 + 质量评分。"

## §2 分（60-90s）

**① 三层架构**：
- 文件记忆：项目级 AGENTS.md / tasks / decisions（人工可读）
- 语义 Store：SQLite 跨会话回忆（类型化抽取 + 关联链 + 质量评分 1-5）
- memory_agent：**并列执行体**（多 worker 队列 + 指纹幂等去重），SSE done 后后台写，不拖慢流
**② 检索升级**：时间衰减 + 窗口裁剪（画像优先）
**③ 权衡/追问点（async 教训）**：记忆抽取是额外 LLM 调用，**不能同步阻塞 done**——fire-and-forget（asyncio.create_task，内部全容错）；质量评分防垃圾记忆入库。

## §3 流程图

```
🟦 对话流 done → memory_agent 队列（并列执行体）
   ├─ 指纹幂等去重 → LLM 抽取 → Store 写入（质量评分）
   └─ 不阻塞 SSE（后台 fire-and-forget）
检索：时间衰减 + 窗口裁剪 + 画像优先
```

## §4 总（20s）

> "记忆不是把对话全存下来——是**抽取值得记的**（质量评分）、**异步写**（不拖慢）、**按相关性取**（衰减/裁剪）。并列执行体是我对'后台任务不阻塞主链路'的落地。"
