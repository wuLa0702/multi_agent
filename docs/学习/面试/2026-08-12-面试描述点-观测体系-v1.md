## §1 总（30s）

> "撞限根因不可见，是因为**观测有盲区**——审计只覆盖主 Agent 层、子代理内部看不见。我做了**行为层 + 推理层双层观测**：工具审计全量 JSONL + 推理层 trace（模型输入摘要/工具/子代理），三层根因定位沙箱循环。"

## §2 分（60-90s）

**① 问题**：task-001 循环 50 轮撞 recursion limit，根因不可见（审计只看得到主 Agent）。
**② 方案（双层观测）**：
- **行为层 ToolAudit**：工具调用全量 JSONL（谁调了什么，脱敏截断）
- **推理层 trace**：每轮模型输入摘要/工具调用/子代理启停，`TraceEvent` 领域对象封装，`parent_ids` 区分层级
- **并发信号量函数工厂**：`get_stream_semaphore()`（环境配置化）
**③ 权衡/追问点**：trace 是成本（每轮模型输入都要记）→ 摘要而非全文；"慢的真相要靠数据，不靠直觉"。

## §3 流程图

```
🟦 行为层 ToolAudit：工具调用全量 JSONL（只记不拦 + 脱敏）
🟥 推理层 trace：模型输入摘要 / 工具 / 子代理启停（parent_ids 层级）
   → 三层根因定位：沙箱循环 → 爬虫 → 写文件 → 动机冲突
```

## §4 总（20s）

> "观测是工程底线——审计管'做了什么'，trace 管'为什么这么做'；没有它，撞限这类问题只能靠猜。"
