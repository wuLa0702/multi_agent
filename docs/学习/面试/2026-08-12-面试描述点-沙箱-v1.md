## §1 总（30s）

> "沙箱用 **OpenSandbox**：agent 跑代码/命令、工作区文件上传下载，**会话级连接池**（复用续期 + 空闲回收 + 资源限额）。配合受控抓取，沙箱**断网只做计算**。"

## §2 分（60-90s）

- 适配层：run_code/run_command + 文件同步（upload/download）+ 生命周期审计
- 连接池：会话级 get_sandbox/sweep/destroy（复用续期，空闲回收）
- 安全：路径前缀校验 + 输出截断 + **网络隔离**（egress 断网，云端验证）
- 权衡：Windows Docker 不支持 NetworkPolicy → 云端 Linux 部署时验证（诚实）

## §3 总（20s）

> "沙箱是执行面 + 安全边界——计算在隔离环境、网络走受控工具；连接池解决会话级资源管理。"
