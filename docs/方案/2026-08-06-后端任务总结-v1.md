## 1. 架构全景 <span style="color:#fff;background-color:#e11d48;border-radius:4px;padding:1px 6px;font-size:0.8em">v1</span>

```
前端（React 19）                      ── HTTP/SSE ──▶  FastAPI（api/）
                                                       │ 路由 + SSE 事件流编排（chat.py）
                                                       ▼
┌────────────────────────────── Agent 编排层（agent/）──────────────────────────────┐
│  main_agent：会话级编译图缓存（LRU 32）+ 运行时模型切换 middleware + 流式事件          │
│    ├─ subagents/  YAML 声明式（model 字段按任务选模型）      ├─ memory/  并列执行体    │
│    ├─ middlewares/  token 用量 / 工具审计 / 解释器          ├─ hitl.py  审批配置      │
│    └─ rubrics.py  评分模板库 + 中间件门控                   └─ prompts/ 分层组装      │
└──────────────────────────────┬─────────────────────────────────────────────────────┘
                               ▼
      ┌──────────┬─────────────┼──────────────┬──────────────┐
      ▼          ▼             ▼              ▼              ▼
   llm/       mcp/          sandbox/        core/          db/
 多 provider 工具注册表     OpenSandbox    基础设施        SQLite 仓储
 适配层      + FastMCP     适配层+连接池   （config/       （7 张表）
 （超时重试）  + 外部 client               paths/权限/
                                         日志/模型注册表）

数据流方向（请求 → 响应）：
用户消息 ─▶ chat.py 校验/会话解析 ─▶ get_agent(thread_id)（缓存/构建编译图）
  ─▶ astream_events（_configurable_model 按 model_id 换模型）
  ─▶ 工具调用（经 ToolAudit 审计 → MCP 注册表 → 沙箱/搜索/技能）
  ─▶ 事件流回推（token/tool_call/subagent/done/error）──▶ SSE ─▶ 前端
后台：memory 队列 worker（lifespan 启动）┄ 记忆抽取写 Store/文件
```


## 4. 核心函数盘点（按模块） <span style="color:#fff;background-color:#e11d48;border-radius:4px;padding:1px 6px;font-size:0.8em">v1</span>

> 优先级：**P0** 核心链路（编排/流式/执行/存储真相源）｜ P1 辅助支撑。私有函数仅在核心链路列出。

### 4.1 agent/main_agent.py（P0 全量）

| 函数 | 职责 | 优先级 |
|------|------|--------|
| `get_agent(thread_id)` | 会话级编译图缓存（有界 LRU 32 + 双重检查锁） | P0 |
| `_build_agent(thread_id)` | 构建单个会话 deepagents 图（工具/middleware/断点/权限装配） | P0 |
| `_configurable_model` | 运行时模型切换 middleware（每次调用按 model_id 换模型） | P0 |
| `stream_agent_events()` | 事件流：token/tool_call/subagent（v2 多事件分发 + 并发限流） | P0 |
| `stream_agent_tokens()` | token 流（v2 兼容回退层） | P0 |
| `init_checkpointer()/init_store()` | 断点/记忆存储生命周期（lifespan 管理，async 连接） | P0 |
| `rebuild_agent()` | 失效缓存重建（Skill 安装/卸载后） | P1 |

### 4.2 api/chat.py（P0 全量）

| 函数 | 职责 | 优先级 |
|------|------|--------|
| `chat_stream` | SSE 流式对话入口（新消息/断点恢复分流） | P0 |
| `_event_stream` | 流内编排：模型调用 → 事件分发 → 记忆/标题后台任务 | P0 |
| `_resolve_session / _prepare_new_messages / _validate_request` | 会话定位 / 消息组装 / 请求校验（互斥等） | P0 |
| `_save_memory_in_background / _generate_title_in_background` | 后台旁路（失败降级不阻断） | P1 |

### 4.3 sandbox / mcp（P0 执行面）

| 模块 | 函数 | 职责 | 优先级 |
|------|------|------|--------|
| sandbox/adapter | `run_code / run_command / write_file / upload_file / download_file / destroy` | 沙箱生命周期与执行（资源限额+超时） | P0 |
| sandbox/pool | `get_sandbox / sweep / destroy` | 会话级连接池（复用续期 + 空闲回收） | P0 |
| mcp/tools/sandbox_tool | `run_code_in_sandbox / run_command_in_sandbox / upload_workspace_file / download_sandbox_file` | 工具层封装（路径前缀校验 + 输出截断） | P0 |
| mcp/tools/search | `internet_search` | 博查搜索（国内直连） | P0 |
| mcp/tools/skill_tool | `run_skill_script` | 技能脚本执行闭环 | P0 |

| mcp/client | `connect_all / reload / get_tools` | 外部 MCP 连接与工具收集（lifespan） | P0 |

### 4.4 memory（P0 全量）

### 6.2 关键 settings 字段（core/config.py）

| 字段 | 默认 | 用途 |
|------|------|------|
| `llm_provider` / `event_stream_v3` | deepseek / True | 默认厂商 / 多事件流 |
| `interpreter_enabled` / `interpreter_ptc` | False / internet_search | 解释器门控 + 只读白名单 |
| `subagent_isolation` | False | P2 子代理隔离编译 |
| `hitl_enabled` / `rubric_enabled` | False / False | HITL 审批 / Rubric 自评（2026-08-06） |
| `sandbox_idle_ttl` 等 | — | 沙箱池回收 |

### 6.3 .env（24 键，只存变量名）
