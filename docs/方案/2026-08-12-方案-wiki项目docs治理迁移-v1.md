## 4. 分·执行步骤（新会话按序执行）

> ⚠️ 执行前确认：wiki 项目 git 状态干净（`cd /d/gtiHub/llm_wiki_selfbuild && git status`），有未提交改动先 stash。

```
步骤 1：备份
  - cd /d/gtiHub/llm_wiki_selfbuild && git status 确认干净
  - 必要时 git stash 未提交改动

步骤 2：复制规范文件
  - 复制 multi_agent/docs/规则/{文档规范,文档治理规则,SOP}.md → wiki/docs/规则/
  - 复制 multi_agent/docs/{索引.md,功能更新日志.md} → wiki/docs/（清空重建）
  - 复制 multi_agent/.claude/rules/05-docs-placement.md → wiki/.claude/rules/（如存在）
  - 修改文档规范.md 适用范围为 wiki 项目（如适用）

步骤 3：建中文目录骨架
  - mkdir -p docs/{架构,决策,评审,学习,踩坑,归档,参考,规则,临时,图片和附件}
  - 每个空目录加 .gitkeep

步骤 4：迁移现有 docs 文件（按 §2.1 映射）
  - 重命名：加 YYYY-MM-DD- 日期前缀（用 git log 查创建日，无历史用今天）
  - 归类：按 §2.1 移到对应中文目录
  - 补文档头：每个文件按《文档规范.md》加 📋/📌/📝 四要素 + 目录
  - 用 git mv 保留历史

步骤 5：清理旧英文目录
  - 移除 decisions/ discussions/ features/ legacy/ testing/（内容已迁移）

步骤 6：重建索引
  - 按新目录结构重写 docs/索引.md（分类列出所有文档）

步骤 7：验证
  - grep 检查无旧英文目录残留
  - 索引可导航（点每个链接存在）
  - git status 确认只动 docs/，无 src/ 改动
```
